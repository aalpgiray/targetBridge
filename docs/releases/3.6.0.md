# TargetBridge 3.6.0

TargetBridge 3.6.0 is a feature release focused on resilient receiver setup,
adaptive streaming, and clearer macOS permission onboarding.

## Highlights

- Remember discovered receivers by stable identity, so reconnecting a
  Thunderbolt or network interface does not discard the selected receiver.
- Preserve saved display profiles, codec preferences, and extended-desktop
  placement when older receiver identities migrate to a stable UUID. Existing
  preferences under the new identity take precedence.
- Choose Automatic, H.264, or HEVC compression per receiver. Automatic safely
  falls back to compatible hardware when the requested codec is unavailable.
- Add Full HD and Full HD 60 stream profiles for non-Retina 1080p receivers.
  They use a native 1920 × 1080 1x virtual display to avoid unnecessary scaling.
- Capture the virtual display directly in headless mirror sessions while keeping
  Audio Relay available through an auxiliary audio capture.
- Add the Sender permission assistant for Screen Recording, Accessibility, and
  Input Monitoring. It requests the macOS prompts and refreshes when returning
  from Privacy & Security.
- Declare the Receiver bundle's actual minimum macOS version from its executable
  and bundled libraries, so an incompatible runtime is caught before launch.

## Upgrade

Update both Sender and Receiver together. Replace older copies in Applications
rather than keeping multiple app copies with the same bundle identifier.
macOS may request privacy approval again after an update. Ad-hoc builds cannot
guarantee permission continuity. Builds signed with the same persistent
certificate retain the application identity macOS uses to associate consent;
the first identity migration may require approval once. TargetBridge never
modifies the TCC permission database directly.

The Sender requires macOS 14 or later. The prepared Receiver packages require
macOS 14 or later on Intel and macOS 15 or later on Apple Silicon. The Receiver
source targets macOS 11, but older-system compatibility also depends on its libraries; the
Big Sur compatibility report in [#167](https://github.com/swellweb/targetBridge/issues/167)
remains open. For Input Dockstation, check the permission matrix on both Macs.

## Validation

The release candidate passes 175 Sender unit tests, the stable receiver
identity test package, and 654 Receiver parser, input-queue, watchdog, and
profile checks. These automated checks do not replace a real two-Mac test of
the selected stream profile, audio relay, and input role.

## Known Limitations

Intermediate Retina scaling for 16:10 Receiver displays is still being
investigated in [#207](https://github.com/swellweb/targetBridge/issues/207).
The experimental lossless video path and Linux Receiver are not included.
